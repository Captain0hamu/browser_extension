# PDF Hidden Text Revealer

PDF内のテキスト描画属性と最終描画結果を解析し、不可視テキストを本来の座標へ可視レイヤーとして書き込んだ修復PDFを生成・表示するChrome/Chromium拡張機能です。処理はローカルで完結します。

自動検出する効果は、白に近い塗り色、塗りの不透明度が0、PDFの不可視テキスト描画モード（`3 Tr` / `7 Tr`）に加え、文字座標の最終描画結果が単色になっている状態（後から重ねたBoxなどによる遮蔽候補）です。検出した文字列をPDFに埋め込まれた元フォントで再エンコードし、元の座標・角度・大きさに合わせた選択可能なテキストとして最前面へ追加します。ページ画像への変換や文字画像の貼り付けは行いません。

生成物はPDFのまま表示され、「修復PDFを保存」から一般的なPDFビューアでも文字が見えるPDFをダウンロードできます。「検出位置を強調表示」を有効にすると黄色背景と赤枠も表示されます。通常の抽出テキストは折りたたみ内で確認でき、全ページ分のコピー・TXT保存も可能です。

## 使い方

1. `chrome://extensions` を開く。
2. 「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」で、このディレクトリを選ぶ。
4. ツールバーの拡張機能アイコンを押し、開いたタブでPDFを選択する。

Firefox版は兄弟ディレクトリ `../pdf-hidden-text-revealer-firefox` にあります。

内蔵PDFビューアの画面へスクリプトを注入するのではなく、拡張機能自身でローカルPDFを解析します。そのためブラウザのPDFビューア制約や元の見た目にある不可視効果に依存しません。

## 制限

- スキャン画像だけのPDFには文字レイヤーがないため、OCRが必要です。
- 暗号化PDFは、PDF.jsが対応するパスワード入力を別途実装する必要があります。
- 単色領域の判定はヒューリスティックです。意図的に背景と同色にした文字も候補になることがあります。
