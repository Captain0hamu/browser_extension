# PDF Hidden Text Revealer

PDF内のテキスト描画属性を解析し、元のPDFページを表示したまま不可視テキストを本来の座標へ復元するChrome/Chromium拡張機能です。処理はローカルで完結します。

自動検出する効果は、白に近い塗り色、塗りの不透明度が0、PDFの不可視テキスト描画モード（`3 Tr` / `7 Tr`）です。PDF.jsで元ページを描画し、検出した文字列を元の座標・角度・大きさに合わせて黄色背景と赤枠で重ねます。「不可視文字をページ上に表示」でオーバーレイだけを切り替えられます。通常の抽出テキストは折りたたみ内で確認でき、全ページ分のコピー・TXT保存も可能です。

## 使い方

1. `chrome://extensions` を開く。
2. 「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」で、このディレクトリを選ぶ。
4. ツールバーの拡張機能アイコンを押し、開いたタブでPDFを選択する。

Firefox版は兄弟ディレクトリ `../pdf-hidden-text-revealer-firefox` にあります。

内蔵PDFビューアの画面へスクリプトを注入するのではなく、拡張機能自身でローカルPDFを解析します。そのためブラウザのPDFビューア制約や元の見た目にある不可視効果に依存しません。

## 制限

- スキャン画像だけのPDFには文字レイヤーがないため、OCRが必要です。
- 暗号化PDFは、PDF.jsが対応するパスワード入力を別途実装する必要があります。
